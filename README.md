# studycue
it project web for studying idk
1. Unzip the folder and open index.html in Chrome or Edge on a laptop (needs internet for the phone detector and fonts).
2. Allow the camera when asked. StudyCue does not work without it.
3. StudyAI: open StudyAI > "API key" and paste a free Gemini key from https://aistudio.google.com/apikey
   (or put it in config.js).
Tip: if the camera is blocked on file://, run a local server:  python3 -m http.server 8000  then open http://localhost:8000
